MOPL# documentation

A small interpreted language built around tags, written values, and a strict rule about how many times you've written to something. Every example on this page has been run against the interpreter — nothing here is speculative.

01Setup

MOPL# compiles to a native binary through a small C interpreter core. The built-in Gfx.* API provides a dependency-free terminal-backed canvas, so the language core does not require a GUI framework.

shell
chmod +x build.sh
./build.sh
./mopl run script.mopl

A C11 compiler is sufficient. build.sh builds the interpreter from mopl.c. The language itself does not depend on a second Window / In / At graphics syntax.

02Your first script

first.mopl
Tag.x = num.5
Terminal 'x'
$ ./mopl run first.mopl
5

Tag.x = num.5 declares a tag named x, of type num, holding 5. Terminal 'x' prints its current value.

03The + Law

Every write to an existing tag after its first must be marked with one more + than the last write. Writing with the correct count doesn't just permit the write — it accumulates the new value onto the old one.

accumulate.mopl
Tag.x = num.5      // 1st write, 0 '+' — sets x = 5
Tag.x += num.10    // 2nd write, 1 '+' — adds: x = 5 + 10
Terminal 'x'
Tag.x ++= num.20   // 3rd write, 2 '+' — adds: x = 15 + 20
Terminal 'x'
output
15
35
the law is strict

Skip a +, or add an extra one, and the interpreter rejects the write outright rather than doing something approximate. The tag keeps its old value.

mismatch.mopl
Tag.x = num.5
Tag.x ++= num.10   // wrong — this is write #2, needs exactly one '+'
Terminal 'x'
output
runtime error: '+' count does not match assignment level for 'x'
5

Try it

This mirrors the interpreter's own write-count check. Name a tag, write to it a few times, and watch when the Law accepts a write versus rejects one.

04Data types

Four tag types. Each accepts a different literal after the type prefix.

num state blea logic
num
Tag.a = num.42

Signed integer. Accumulates on write, per the + Law.

state
Tag.b = state.true

Boolean, stored as 1/0. Accumulates numerically on write, same as num.

blea
Tag.c = blea.Hello World

Text. Overwrites on reassignment — it does not concatenate.

logic
Tag.d = logic.

A logic value. Named logic blocks can be defined, called, and returned from.

05Terminal

Terminal '<name>' prints a tag's current value: the integer for num, true/false for state, the raw string for blea. A logic tag prints nothing.

06Op of

Performs an operation on two operands and stores the result in a special tag called _. Operands can be tag names or literal integers.

math.mopl
Tag.a = num.4
Tag.b = num.3
Op of a add b ==
Terminal '_'
output
7

rnd and len

Op of rnd <min> <max> returns a random integer in an inclusive range. Op of len <tag> returns a blea tag's character count.

rnd-len.mopl
Tag.msg = blea.Hello World
Op of len msg ==
Terminal '_'

Op of rnd 1 10 ==
Terminal '_'
output (rnd varies run to run)
11
3

07Dif

Dif in <name>[, <name>...] prints each tag's type and level — the number of writes performed on it so far.

inspect.mopl
Tag.x = num.1
Tag.x += num.2
Tag.y = state.true
Tag.z = blea.hi
Dif in x, y, z
output
x = num, level 2
y = state, level 1
z = blea, level 1

08Cycle

Cycle <N> captures every line up to the matching EndCycle and executes the body N times. Cycles can contain conditionals, terminal commands, operations, graphics commands, and nested cycles.

loop.mopl
Tag.n = num.0
Cycle 5
Tag.n += num.1
Terminal 'n'
EndCycle
output
1
2
3
4
5
nested execution

A Cycle body is executed as a real block rather than merely copied as text. This means a cycle can contain Check, Else, logic calls, and other nested Cycle blocks.

the + Law inside loops

A captured line has the same literal + count on every replay, even though the tag's level keeps climbing. Inside a Cycle body only, a count mismatch on an existing tag is treated as another accumulation. Outside a loop, the strict check from section 3 still applies.

09Check / Else

Check evaluates a condition and executes only the matching branch. Else is optional, and EndCheck closes the block. Conditions can compare tag values or integer literals.

conditional.mopl
Tag.x = num.5
Check x greater 0
    Terminal 'x'
Else
    Terminal '_'
EndCheck
output
5

Comparison forms

formmeaning
== / eqequal
!= / neqnot equal
< / ltless than
<= / lteless than or equal

>= / gtegreater than or equal

not / !logical negation

Conditions may be nested. A false branch is skipped without executing the commands inside it.

10Logic blocks

A logic block is executable code. Define it with a name, optionally list parameters, close it with EndLogic, and invoke it with Call. Return places the returned value in the special tag _.

function.mopl
logic greet name
    Terminal 'name'
EndLogic

Call greet 'hello'

logic double x
    Op of x times 2 ==
    Return _
EndLogic

Call double 7
Terminal '_'
output
hello
14
tagged logic

Logic blocks can also be referenced through logic tags such as Tag.fn = logic.greet. The block is stored as executable logic rather than an empty placeholder.

11Input

Input reads a line from standard input. Use it when a script needs a value supplied while the program is running.

input.mopl
Input name
Terminal 'name'

12Gfx commands

Opens a native window and draws into an offscreen canvas. Colors are packed 32-bit integers in 0xAARRGGBB order — alpha first.

draw.mopl
Gfx.init "My Window" 400 300
Gfx.clear 4278190080
Gfx.rect 10 10 50 50 4294901760
Gfx.circle 200 150 40 4278255360
Gfx.line 0 0 399 299 4294967295
Gfx.text "hi" 20 20 16 4294967295
Gfx.present
Gfx.poll
Gfx.shutdown
commandarguments
Gfx.init"title" width height
Gfx.clearcolor
Gfx.rectx y w h color
Gfx.rect_outlinex y w h thickness color
Gfx.linex0 y0 x1 y1 color
Gfx.circlecx cy radius color
Gfx.text"string" x y size color
Gfx.pixelx y color
Gfx.present— pushes the canvas to the window, paced to 60 FPS
Gfx.poll— processes window/input events, call once per frame
Gfx.shutdown— closes the window

For an animated or interactive program, put Gfx.poll and Gfx.present inside a Cycle, once per frame.

14Limitations

  • blea tags overwrite on reassignment rather than concatenating — Tag.msg += blea.more replaces the string.
  • The + Law's write-count check is strict everywhere except inside a Cycle body.
  • Gfx.* uses the built-in terminal-backed canvas rather than the removed Window / In / At syntax.
  • Logic execution is sequential; recursive or mutually recursive logic should be treated as an advanced use of the interpreter.

15VS Code setup

A minimal .vscode/tasks.json with a build task and a run-current-file task lets you build and run with a keybinding instead of switching to the terminal.

.vscode/tasks.json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "MOPL#: Build Interpreter",
      "type": "shell",
      "command": "bash build.sh",
      "group": "build"
    },
    {
      "label": "MOPL#: Run Current File",
      "type": "shell",
      "command": "./mopl run \"${file}\"",
      "group": { "kind": "test", "isDefault": true },
      "dependsOn": ["MOPL#: Build Interpreter"]
    }
  ]
}
